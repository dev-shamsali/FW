# Rhea.js v0.1.0-alpha.1

**Choose your stack, get a running API.** `npx create-rhea my-api` now asks for TypeScript or JavaScript, ES Modules or CommonJS, and MongoDB, MySQL or no database.

> Alpha software. The API can change between alpha releases. It is not production-ready and has had no independent security review.

## What is new since 0.1.0-alpha.0

- **Interactive `create`** with arrow-key prompts: language, module system, database, install now. Every question has a flag for scripts: `--ts --js --esm --cjs --db none|mongodb|mysql --install --yes`.
- **JavaScript support**, both ES Modules and CommonJS. Generators (`rhea generate ...`) follow the project's choice.
- **MongoDB and MySQL** setup: official drivers only (`mongodb`, `mysql2`), pooled connection, connect before the server listens, clean close on shutdown, validated `DATABASE_URL`, and `GET /health/ready` that checks the database.
- **A working first API**: `GET /api/rhea` returns the framework name and "developed by Shams Ali Shaikh", and the dev server prints a banner.
- **Scripts**: `npm run dev` uses nodemon (graceful restart on every change), `npm start` runs plain node, `npm test` runs Vitest.
- `rhea docker` writes a Dockerfile for your language and adds the database service to `docker-compose.yml`.
- Fixes: generators are all-or-nothing, reserved words are refused, `create` verifies the install finished.

## Install

```bash
npx create-rhea my-api
cd my-api
npm install
npm run dev
```

Open http://localhost:5000/api/rhea. Requires Node.js 20.19 or newer.

## Verified before release

Every combination of language and module system was created, installed, linted, type-checked, tested, built, started and queried. TypeScript and JavaScript, ESM and CommonJS were run on Node.js 20, 22 and 26. MongoDB 7 and MySQL 8.4 were tested with real containers (connect, readiness, shutdown, and the database-down failure). The CI matrix covers Linux, macOS and Windows.

## Known limitations

- No ORM or query layer: you write your own queries.
- No authentication yet.
- Rate limiting counters live in process memory (not shared across instances).
- `docker compose` files are checked structurally, not run with Compose.
- `rhea security` is a static check, not an audit or penetration test.
- No benchmarks have been run, so there are no performance claims.
