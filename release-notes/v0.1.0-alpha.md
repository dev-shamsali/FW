# Rhea.js v0.1.0-alpha

**The first alpha of Rhea.js: a secure, convention-driven backend framework for Node.js, built on Express 5.**

> Alpha software. The API can change between alpha releases. It is not production-ready and has had no independent security review.

## What it is

Express stays the HTTP engine. Rhea.js adds the architecture around it: a project layout, security defaults, validation, error handling, logging, a CLI and a plugin API. Made by Shams Ali Shaikh. MIT licensed.

## What is included

- `@rheajs/core`: `createApp()` with request IDs, structured logging with secret redaction, Helmet, CORS (denied by default), rate limiting, body size limit, request timeout, prototype-pollution guard, standard error and response shapes, Zod validation and environment parsing, lifecycle hooks, graceful shutdown, plugin API.
- `@rheajs/cli`: `rhea create | dev | build | start | generate | test | doctor | security | docker | info`.
- `create-rhea`: `npx create-rhea my-api`.
- Documentation (24 pages) and a website: https://rhea.devcodehub.cloud

## Install

```bash
npx create-rhea my-api
cd my-api
npm install
npm run dev
```

Requires Node.js 20.19 or newer.

## Try it

```bash
npx rhea generate module users
npm test
npx rhea build && npx rhea start
npx rhea doctor
npx rhea security
```

## Known limitations

- Rate limiting counters live in process memory (not shared across instances).
- No authentication and no database adapters yet.
- `validate()` is synchronous (no async Zod refinements).
- Verified on Linux with Node.js 20, 22 and 26. macOS and Windows are covered by the CI matrix only.
- `rhea security` is a static check, not an audit or penetration test.
- No benchmarks have been run, so there are no performance claims.
